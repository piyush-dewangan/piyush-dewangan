## About me

I build production web applications used by investors every day, from KYC onboarding and payment flows
to stock screeners and portfolio trackers. I like the full stack: fast, well-tested frontends, REST
services behind them, and a CMS that lets non-developers ship content without waiting on engineers.

Outside of work I go deeper on how systems actually work. My latest project is a Redis-compatible data
store written from scratch in Java, with its own event loop, wire protocol parser and crash-safe storage.

- 🔭 **Working on:** full stack products at [Value Research](https://www.valueresearchonline.com/)
- 🌱 **Learning:** Java backend engineering, LLM APIs and AI agents
- 💬 **Ask me about:** React and Next.js performance, CMS-driven architecture, frontend testing
